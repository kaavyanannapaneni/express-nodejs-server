# Express Node.js Server

A basic Node.js server using Express and Nodemon.

---

## Requirements

- Node.js installed

Check versions:

```bash
node -v
npm -v
```

## Install Dependencies

```bash
npm install
```

Install Express:

```bash
npm install express
```

Install Nodemon (development dependency):

```bash
npm install --save-dev nodemon
```

---

## Run Server

Run normally:

```bash
npm start
```

## Server URL

```text
http://localhost:3000
```

## Features

- Installing 3P express package using "npm"
- Setting up basic Express server and handling requests and response
- Parsing user data with express and storing it in a file 
- Accessing / Reading user data from the file and returning dynamic    responses (HTML code)
- Route handling
- Using nodemon for development and auto restart during development
